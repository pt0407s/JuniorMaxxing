## The system in one paragraph

Process during class, not after. Convert notes to Anki cards the same day. Do Anki reviews daily (20-30 min, all subjects). Do homework with your phone in another room. Interleave problem types for math/science. Start lab reports the day of the lab. Prep for tests 5 days out using the test-prep checklist. Never miss a Minor assignment. Track every grade. Never miss twice on the daily minimum routine.

## Non-negotiables

1. **Anki every day.** Even if it's one card. The streak matters more than the volume.
2. **Phone in another room while studying.** Not on desk. Not on silent. Another room.
3. **Log every grade the day you get it.** In grade-tracker.csv.
4. **Never miss twice.** Missed a day of Anki? Do one card today. Don't let two days stack.
5. **Start every lab report the day of the lab.** Data section at minimum.

## When you're struggling

Read [MENTOR.md](MENTOR.md). Talk to someone real. The systems in this repo work, but only if you execute — and execution is an emotional problem, not a knowledge problem. The mentor skill is built to help with that part.
