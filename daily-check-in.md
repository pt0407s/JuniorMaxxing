# Daily Check-In — Nightly 2-Minute Review

> Do this every night after dinner, before any screen time.
> Print this. Keep it on your desk. Check the boxes.
> Takes 2 minutes. This is the feedback loop that makes everything else work.

---

## Date: ___________ Day: ___ (A or B)

### 1. Anki — did you do it?

- [ ] Did at least 1 card per AP class today? (6 cards, ~5 min)
- [ ] Streak: ___ days

> If no: What blocked it? Fix the system, not yourself. Do 1 card right now.

### 2. What's due tomorrow?

- [ ] Checked every class for tomorrow's assignments? (2 min)
- [ ] Any tests/quizzes tomorrow? → Which class? _________
- [ ] Any homework due tomorrow? → Which class? _________

### 3. What did you turn in today?

- [ ] Logged every grade in grade-tracker.csv? (Class, Assignment, Major/Minor, Grade, Date)
- [ ] Ran `python3 grade-calculator.py` to see where you stand? (if any grades came back)

### 4. The one question

**What is the single most important thing I need to do for school tomorrow?**

Answer: _________________________________________________

> Not 5 things. One thing. The test you need to study for. The essay that's due.
> The homework worth the most points. Identify it. Then do it first.

### 5. Phone + sleep

- [ ] Phone is charging in another room (NOT bedroom, NOT desk)
- [ ] Alarm is set for tomorrow
- [ ] Backpack is ready by the door
- [ ] Study materials set up for tomorrow

### 6. Honest check

**Did I actually try today, or did I just go through the motions?**

Circle one: TRIED / MOTIONS / SKIPPED

> If MOTIONS: tomorrow, pick ONE class to actually engage in. Just one.
> If SKIPPED: no guilt. Do 1 Anki card right now. Never miss twice.

---

## Weekly (Sunday night — add these to your Sunday planning)

- [ ] Updated grade-tracker.csv with all grades from the week
- [ ] Ran grade-calculator.py — know your standing in every class
- [ ] Reviewed upcoming tests/quizzes for the next week
- [ ] Checked AP Classroom for new assignments/videos
- [ ] Adjusted study plan based on what's actually happening (not what you planned)
