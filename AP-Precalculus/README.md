# AP Precalculus

## Overview
AP Precalc covers: polynomial/rational functions, exponential/logarithmic functions, trigonometric functions, polar/parametric/vector functions. Newer AP course (first offered 2023-24).

## Grading
Major 60% (tests, exams) / Minor 40% (HW, classwork, quizzes)

## Class strategy
- **Math is reps** — do every assigned problem + 5 more from each section
- **Interleaved practice** — DON'T do 20 of the same problem type. Mix problem types within a study session (research shows this boosts scores dramatically — d=0.83 in Rohrer 2020)
- **Keep an error log** — every mistake logged with WHY you got it wrong. Review before each test. This alone can add 3-4 points.
- **Show all work** — teachers give partial credit. Wrong answer + good work > right answer + no work
- **Use Desmos to check** but never to replace hand-work
- **Trig identities** are the biggest time sink — drill until automatic
- **Anki:** Formulas, identities, parent function shapes — cloze deletion

## Key resources
- Khan Academy AP Precalculus (officially partnered with College Board)
- AP Classroom AP Daily videos
- Desmos (for graphing/checking)
- Textbook end-of-chapter problems

## 6-week approach
- Math tests are the most predictable — if you can do the homework problems, you can do the test
- **Do homework the day it's assigned** while the lesson is fresh
- **Before tests:** Do a mixed problem set (interleaved) from all sections covered, not just re-doing homework
- **Error log review** the night before every test
