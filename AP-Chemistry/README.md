# AP Chemistry

## Overview
Units: atomic structure, bonding, reactions/stoichiometry, thermodynamics, kinetics, equilibrium, acids/bases, electrochemistry. Hardest to cram — start earliest.

## Class strategy
- **Do problem sets the day they're assigned** while the lesson is fresh
- **Master stoichiometry and mole conversions first** — everything builds on it
- **Make a formula/constant sheet** and update it every unit — you'll need it for every test
- **Lab reports:** Format perfectly, include error analysis, use significant figures correctly. Labs are where careless points leak.
- **Interleaved practice** — mix problem types when studying (kinetics + equilibrium + thermo together)
- **Anki:** Polyatomic ions, solubility rules, strong acids/bases, common redox half-reactions, formulas — cloze deletion
- **Office hours for anything you don't fully get** — chem compounds; falling behind = death
- **Show all work with units** — dimensional analysis catches 80% of mistakes

## 6-week approach
- Chem tests are problem-heavy — practice problems > re-reading notes
- **Before tests:** Do a mixed problem set (interleaved) covering all topics from the 6-week period
- **Lab reports due?** Start data section the day of the lab, finish discussion 2 days before due
- **Memorize early:** Ions, formulas, solubility rules — don't leave these to the night before
