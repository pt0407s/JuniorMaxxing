## Daily routine (B Day class — homework due A Day night)

### Night after B Day (process + homework):
- [ ] Convert class notes → Anki cards (10-15 min)
- [ ] Do assigned problem sets (25-30 min) — **while lesson is fresh**
- [ ] Update formula/constant sheet with anything new
- [ ] Anki reviews (all subjects, 20-30 min total)

### Night before B Day (pre-read):
- [ ] Skim next topic in textbook (10-15 min)
- [ ] Watch AP Daily video for next topic if available (10 min)

### Lab days:
- [ ] **Start lab report data section THE DAY OF THE LAB** — non-negotiable
- [ ] Finish discussion section 2 days before due date
- [ ] Use rubric as checklist: data, analysis, error analysis, significant figures, units

## Test prep protocol (starts 5 days before test)

See [test-prep-checklist.md](../test-prep-checklist.md) for the full checklist.

### Chem-specific test prep:
- **Day -5:** Make a 1-page summary of all formulas + when to use each
- **Day -4:** Do a mixed problem set (interleaved — mix kinetics + equilibrium + thermo)
- **Day -3:** Do past FRQs from the units being tested — time yourself
- **Day -2:** Review error log (every mistake you've logged all unit)
- **Day -1:** Do one more mixed problem set. Check all units. Sleep 8 hours.

### On the test:
- Show all work with units — dimensional analysis catches 80% of mistakes
- Check significant figures on every calculated answer
- If stuck, write the relevant equations and what you'd do — partial credit
- Re-check every answer if you finish early

## 6-week approach
- Chem tests are problem-heavy — practice problems > re-reading notes
- **Before tests:** Mixed problem set (interleaved) covering all topics from the 6-week period
- **Lab reports due?** Start data section day of lab, finish discussion 2 days before due
- **Memorize early:** Ions, formulas, solubility rules — don't leave to night before
- **Office hours for anything you don't fully get** — chem compounds; falling behind = death
