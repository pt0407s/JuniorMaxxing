# AP Biology

Target: 97+ in class. School starts Aug 12.

## Folder structure

- `units/` — CED (Course & Exam Description) for each unit, converted to text from the official College Board PDFs
- `review/` — review resources (one-pagers; note: original is image-based, see `pdf_originals/`)
- `notes/` — personal notes and study guides
- `pdf_originals/` — original PDFs kept for reference/visuals

## Class strategy

- Pre-read the CED unit section BEFORE the teacher covers it in class
- Bozeman Science (Paul Andersen) video the night before each topic
- Anki deck for vocab — maintain all year
- Lab reports: perfect format, sig figs, error analysis, conclusion tied to concept
- FRQ practice from released exams — bio rubrics are specific, learn the phrasing
- Big Ideas to thread through everything: Evolution (EVO), Energetics (ENE), Information Storage & Transmission (IST), Systems Interactions (SYI)
