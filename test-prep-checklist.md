# Test Prep Checklist — 5 Days Out

> Start this 5 days before ANY test. Copy this for each test. Don't skip steps.

## Test info
- **Class:** _________
- **Date:** _________
- **Units/topics covered:** _________
- **Format:** MCQ / FRQ / both / other: _________
- **Major or Minor?** _________ (if Major, this is 60% of your grade — over-prepare)

---

## Day -5: Organize and summarize

- [ ] Identify exactly what's on the test (which units, which topics)
- [ ] Make a 1-page summary sheet — all key formulas, terms, concepts
- [ ] List what you DON'T fully understand — these are your focus areas
- [ ] Gather all materials: notes, homework, quizzes, textbook, AP Classroom

**Output:** 1-page summary sheet + list of weak spots

---

## Day -4: Active recall + interleaved practice

- [ ] Do a mixed problem set / practice questions (interleaved — mix all topics)
- [ ] Don't do 20 of the same type. Mix problem types within the session.
- [ ] Time yourself if the test is timed
- [ ] Log every mistake in your error log with WHY you got it wrong

**Output:** Completed mixed problem set + updated error log

---

## Day -3: Past FRQs / practice tests

- [ ] Do past FRQs from AP Central for the tested units
- [ ] Time yourself (real exam timing)
- [ ] Score yourself using the scoring guidelines
- [ ] Note where you lost points — these are your remaining weak spots

**For essay classes (Lang, APUSH):**
- [ ] Write 1 practice essay (timed)
- [ ] Compare to student samples on AP Central
- [ ] Note what your essay is missing vs a top-scored sample

**Output:** Completed + scored FRQs/practice test

---

## Day -2: Fill gaps + review errors

- [ ] Review error log — every mistake you've logged this unit
- [ ] Re-do the problems you got wrong on Day -4 and Day -3
- [ ] Focus on your weak spots from Day -5
- [ ] Watch a video on any topic you still don't fully get
- [ ] Do Anki reviews — extra focus on this class's cards

**Output:** All weak spots addressed, all errors re-done correctly

---

## Day -1: Light review + sleep

- [ ] Re-read your 1-page summary sheet
- [ ] Do 5-10 practice problems (easy ones — build confidence)
- [ ] Skim notes one more time — NOT cramming, just refreshing
- [ ] Pack your bag: pencils, calculator (if allowed), eraser, any allowed materials
- [ ] **Sleep 8 hours.** This is non-negotiable. Sleep is when your brain consolidates learning.
- [ ] No screens 30 min before bed

**Output:** Rested, prepared, confident

---

## Day of test: Before you walk in

- [ ] Eat something (brain needs fuel)
- [ ] Skim your 1-page summary one last time (5 min max)
- [ ] Take 3 deep breaths before the test starts
- [ ] Remind yourself: you prepared for 5 days. You know this.

---

## During the test

- [ ] Read every question twice before answering
- [ ] Show all work (math/science) — partial credit is real
- [ ] Check units on every answer (math/science)
- [ ] If stuck, skip and return — don't burn time on one question
- [ ] Write something for every FRQ part — partial credit
- [ ] If you finish early, RE-CHECK every answer. Most lost points are careless mistakes.
- [ ] For essays: write your thesis FIRST. Everything follows from the thesis.

---

## After the test

- [ ] Log the grade in [grade-tracker.csv](grade-tracker.csv) the day you get it back
- [ ] If below 100: What went wrong? Add to error log. Adjust prep for next test.
- [ ] If 100: Note what worked. Repeat it next time.
- [ ] Go to the teacher — even if you got 100. Build the relationship.

---

## Subject-specific additions

### AP Bio / AP Chem / AP Physics 1
- Make formula/constant sheet on Day -5
- Lab reports: use rubric as checklist
- Draw diagrams (free-body diagrams for physics, structures for chem, processes for bio)

### AP Precalc
- Error log review is the highest-ROI habit — do it on Day -2
- Practice both calculator and no-calculator problems
- Drill trig identities until automatic

### APUSH
- Make a timeline on Day -5
- Practice DBQ/LEQ thesis statements on Day -3
- Review all key terms/dates/people in Anki on Day -2

### AP Lang
- Review rhetorical terms on Day -5
- Write 1 practice essay on Day -4
- Read student samples on Day -3
- Practice thesis statements for 5 prompts on Day -2
