# AP Physics 1 (Algebra-Based)

## Overview
Kinematics, forces/Nature's laws, energy, momentum, rotation, SHM, waves/sound, electricity/circuits. Most concept-heavy science AP — math is easy, reasoning is hard.

## Grading
Major 60% (tests, labs, projects) / Minor 40% (HW, classwork, quizzes)

## Class strategy
- **Most concept-heavy science AP** — math is easy, *reasoning* is hard
- **Do NOT memorize formulas blindly** — learn when each applies and the assumptions. The equation sheet is given; knowing *which* to use is the test.
- **Draw free-body diagrams for EVERY force problem** — teachers grade for them
- **Check units on every answer** — dimensional analysis catches 80% of mistakes
- **Show every step in pencil** — partial credit is huge in physics
- **If you can't solve it, write the relevant equations and what you'd do** — partial credit
- **Interleaved practice** — mix kinematics + forces + energy + momentum problems together
- **Master energy bar charts (LOL diagrams) and momentum bar charts** — they make 60% of problems easy
- **Anki:** Formulas (when to use each), key definitions, unit conversions

## Key resources
- AP Classroom AP Daily videos
- Flipping Physics (YouTube) — excellent, aligns with CED
- Khan Academy (for concept gaps)
- The equation sheet is on College Board — print it, learn what each formula is for
- Princeton Review / 5 Steps to a 5 (spring)

## 6-week approach
- Physics tests reward problem-solving over memorization
- **Before tests:** Do a mixed problem set (interleaved) — never do all kinematics then all forces
- **FRQs are long and multipart** — practice pacing. Skip and return if stuck.
- **Lab reports:** Same format as chem/bio — data, analysis, error analysis, conclusion
